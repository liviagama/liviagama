Computer Science student (UNIVAP, 2nd semester) in São José dos Campos, Brazil. I write the vision code that helps an autonomous drone figure out where to land — and I'm aiming that same skill set at eVTOL and urban air mobility.

###

## 🚀 Currently — ThunderQuad, FEAU/UNIVAP

Autonomous drone team, formed two months before our first competition.

- Competed in **EletroQuad SAE BRASIL – Axia Energia 2026**, hosted at UNIVAP, against 27 teams from 9 states + the Federal District
- Reached our first fully autonomous flight one week before competing
- Built the **QR code reading module** (Python + OpenCV) running on a Raspberry Pi 3, used in the autonomous landing mission to decode in flight which base to locate
- Worked with **ArduPilot** and **Mission Planner** on sensor calibration, mission automation, and flight control
- Now migrating onboard processing from Raspberry Pi to an **NVIDIA Jetson Nano** for the 2027 edition

###

## 🛰️ Featured project

> ### [inspecao-visual-superficie](https://github.com/liviagama/inspecao-visual-superficie)
> Python/OpenCV pipeline that detects and classifies defects on metal surfaces — scratches, corrosion, missing rivet holes — for industrial and aerospace inspection.
>
> - Geometric rule-based classifier **vs.** a scikit-learn ML baseline, evaluated on the same held-out test set
> - Synthetic dataset generator with ground truth, so results are reproducible from a clean clone
> - `pytest` coverage and a documented error analysis (where each approach fails, and why)
