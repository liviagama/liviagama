## Featured project

**[inspecao-visual-superficie](https://github.com/liviagama/inspecao-visual-superficie)** — a Python/OpenCV pipeline that detects and classifies defects on metal surfaces (scratches, corrosion, missing rivet holes), for industrial and aerospace inspection. Compares a geometric rule-based classifier against a scikit-learn ML baseline, with a synthetic dataset generator, ground truth, pytest coverage, and documented error analysis.
